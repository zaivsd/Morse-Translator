## Morse Translator
A simple command-line interface Morse code translator written in Python.

## Usage
Run `main.py`.

| Command | Definition |
| :-----: | :--------: |
| morse | Convert a string into Morse code |
| string | Translate Morse code into a string |
| help | Get a list of useful commands |
| exit | Quit the program |

## Requirements
- Python 3
